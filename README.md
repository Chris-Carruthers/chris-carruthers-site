# Chris Carruthers — personal site

Static HTML/CSS/JS. No build step.

```sh
python3 -m http.server 8731   # then open http://127.0.0.1:8731
```

- `index.html`: the page
- `styles.css`: design tokens and layout (olive racing green, cognac leather, butterscotch, instrument-panel dials)
- `site.js`: draws the outcome dials and the platform schematic; the page is complete without it
- `assets/shots/`: product screenshots from demo tenants (each has a `.json` provenance sidecar)
- `PRODUCT.md`, `.impeccable/`: design context and decisions
